## 项目简介

本项目是一个完整的校园二手交易平台（二手物品交易系统），支持普通用户和商家两种角色。普通用户可以浏览商品、加入购物车、下单购买、申请成为商家；商家可以发布商品、管理商品、查看订单；管理员可以审核用户注册、审核商家申请、管理用户。

## 核心功能

### 用户模块
- 用户注册（含图形验证码）
- 用户登录（BCrypt 密码加密）
- 管理员审核用户注册
- 个人信息修改（手机号、邮箱、城市、性别、银行账号）

### 商家模块
- 普通用户申请成为商家（上传营业执照、身份证）
- 管理员审核商家申请
- 商家发布商品（多图片、价格、库存、议价开关）
- 商家管理商品（上架/下架/编辑）
- 商家查看商品列表

### 商品模块
- 首页商品列表展示（分页）
- 商品搜索（按名称）
- 商品排序（价格升序/降序、销量降序）
- 商品详情查看

### 购物车与订单
- 加入购物车
- 购物车管理（修改数量、删除商品）
- 一键下单（从购物车结算）
- 扣减用户钱包余额
- 扣减商品库存
- 增加用户积分（1元=1积分）
- 订单生成（订单号、订单明细）

### 钱包与积分
- 钱包余额查看
- 充值（密码验证，默认密码 0000）
- 提现（密码验证，默认密码 0000）
- 积分累计与展示

### 管理员模块
- 用户列表查看
- 用户审核（通过/拒绝）
- 商家申请审核（通过/拒绝）
